# mc-ignorable

A prefix in `mc:Ignorable` with no namespace declaration in scope (WD REQ-323), for `UndeclaredIgnorableTest`.

The files are the portfolio's round `undeclared-ignorable`, 13 files, each run twice through the Word bridge (Word 16.0.20326.20232,
8 November 2026, the runs agreeing). Each `*-word365.docx` is Word's save of the file of that name. Word repairs `ui-01` to `ui-04` and
`ui-10` to `ui-14`, one prompt an open, and loses nothing; it refuses `ui-05`, so it has no save; `ui-00`, `ui-06` and `ui-07` open silently.
The WD's NOTE under REQ-323 has the rest.
